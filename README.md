## Dependencies

`addons/vrm` (the VRM importer and `VRMTopLevel`) and the MToon shaders are no longer copied into this repository.
Put V-Sekai's godot-vrm (`https://github.com/V-Sekai/godot-vrm`, MIT) and its MToon shader addon under `addons/` before
opening the project; the persona-stream repo manifest checks godot-vrm out at `model/thirdparty/godot-vrm`.
`addons/vmd_motion` (MIT, from lox9973's VMDMotion and EIRTeam's VMDMotionGD) stays.
